# WHYELAB_UIUX-Portfolio

My UIUX Portfolio.

## High Level Ideas

1) Instead of just listing things out, make it more interactive with scrolling. As user is scrolling, expand what the user should be focusing on and then show animation or some picture on what a particular thing is about. Like your experience with TikTok, on scroll, expand and animate the icon then show what you did with pictures or videos.

## Features

1) Track user activity, like who (from which IP address) viewed our profile.

2) Track which part of the website is viewed the most, and which is interacted the most. Then output the analysis results.

3) On hover of the tech stack, you should display the system architecture diagram if there is one.

4) Incorporate some icon animation in some sections with meaning, say on the about me page, have a recruiter stick figure icon that tap on your profile to pop up a contact info window then tap on like your resume, youtube, github... to show something.

5) Does the page work with mobile?
